# 沥林镇域推演 · 三线三桥一张图

沥林是一个镇。镇一级最难的地方是数据少、口径杂、能查到的都是些零散硬数字。这一页把"三线三桥一张图"摆成可以开会用的东西：一张网络图、一次排序、一次对照、一次走访。

单文件离线应用，双击即开，无后端、无登录、不联网、不采集数据。

## 打开方式

双击 `沥林决策模拟器.html`。手机、平板、电脑、大屏四级断点都已适配；`Ctrl+P` 可直接出 A4。

## 五个页面

| 页面 | 看什么 |
|---|---|
| 封面 | 开场画面，可点节点跳转到对应位置 |
| 构建世界 | 20 个主体分批飞入组网，看这个镇由谁撑着 |
| 情景推演 | 三个档位滑块与六种情形，四张联动图跟着一起动 |
| 说明 | 数据从哪里来、哪里没有、看到什么程度就该停 |
| 研究空白 | 数不出来说明的六处，本身就是下一步该去走访的地方 |

## 怎么用

1. 开场：封面到构建世界，把镇的样子先看一遍
2. 参与方判断：发手卡，做五次选择（重要程度、先后次序、承接比例、一个系数、三十天内做什么）
3. 对照：在情景页切档，四张图联动，看自己的判断与页面差在哪
4. 找差异：差在哪一步，翻说明页
5. 会后：三十天走访把数据补齐，再跑一遍

## 一个约定

所有结果页都固定标注"非预测值"，不可关闭。页面上写的是几种情形下的相对结果，不是对沥林未来的判断。
