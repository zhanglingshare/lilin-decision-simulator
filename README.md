# 镇域产业推演 · 沥林「三线三桥一张图」决策推演模拟器

> 缺乏数据时，如何做镇域决策推演？
> 单文件离线应用。双击即开，无后端、无登录、不联网、不采集数据。

---

## 一、这是什么

面向镇域发展决策的场景化推演工具。基于公开可查的硬锚点数据，把**找桥位（SNA）→ 看收益（蒙特卡洛）→ 比立场（AHP）→ 看环境（博弈矩阵）**的完整推演流程做成可交互页面。

**核心定位**：只做查表与播放，不做现场计算。所有结果按情景预置，参与方只做离散选择，组织者按情景切换展示。软件负责把预置结果按情景调出来，让直觉与模型结果对照。

**不是什么**：不是预测工具，不是决策系统，不替代决策者。每个结果页固定标注"非预测值"。

**四步交付**：一张网络图（识别桥位）→ 一次排序（立场选择）→ 一次对照（直觉 vs 模型）→ 一次走访（课后采数回填）。

## 二、页面结构

| 页 | 内容 | 作用 |
|---|---|---|
| **封面** | 全息风格：透视网格、雷达扫掠、弦数据包流动、三桥轮播 | 开场氛围，点节点可直跳首页并高亮 |
| **构建世界** | 20 主体分 6 批飞入组网；邻接矩阵 400 格、度分布、南北配对 65 格 | 让网络先被看见 |
| **情景推演** | 3 个档位滑块 + S1—S6；四张联动图（拖一拖 / 立场排序 / 不确定度 / 关系图） | 直觉与模型对撞 |
| **方法与边界** | 17 张可交互图 | 交代数据来源、依据、限制、纪律 |
| **研究空白** | 6 张图 | 数据不足＝研究空白＝县镇数据底座 |

**S4 参照封存**：口令 `M7-LILIN` 解锁后才可见。未解锁前任何方式不可见。

## 三、怎么用

1. **开场**：封面 → 构建世界（组网动画跑一遍，讲"这个镇长什么样"）
2. **参与方判断**：发放手卡，做五次选择（权重 / 桥位排序 / 承接率 / 系数 / 30 天动作）
3. **模型对照**：情景推演页切档，四张图联动，看直觉与模型差在哪
4. **差异归因**：差异来自哪个假设 → 走上方法与边界页
5. **课后**：30 天走访采数，用真实数据再跑一遍

## 四、技术规格

- **纯前端静态**：HTML + CSS + 原生 JS，无框架、无 CDN、无外部依赖
- **图形**：全部手写 SVG + CSS 动画（未引用 ECharts，避免离线失效）
- **三端适配**：手机 / 平板 / 电脑 / 大屏四级断点
- **打印**：`Ctrl+P` 出 A4，导航隐去、图不切断、封面不印
- **状态**：localStorage 存档位与解锁状态，刷新保留

## 五、数据纪律（不可破）

1. **三轨数据**：A 轨硬锚点（已知）／B 轨档位估计（三档）／C 轨留白（待走访）
2. **血统分级**：A/B/C/D 四级，每条数据标可讲到的程度
3. **口径并列不合并**：如规上 191/211、算力 4万/6万P，并列展示不替参与方作主
4. **缺失显眼标注**：缺的一律画出来，不掩盖
5. **非预测值声明**：每页固定，不可关闭
6. **空白是机会，不是填空许可证**：补数据仍要标来源分等级
